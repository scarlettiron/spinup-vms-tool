Vmynt / Install

Install Vmynt

Vmynt is one self-contained program. Install it from the package manager you already use. You don't need Rust, PowerShell or a runtime of any kind.

Package manager listings appear as each one approves a release, so if one isn't live yet, use a direct download. Then check your host requirements.

Windows

With winget, which is built into Windows 10 and 11:

PowerShell
winget install CodeScarlett.Vmynt

Or with Chocolatey:

PowerShell (as administrator)
choco install vmynt

Open a new terminal afterwards so vmynt is on your PATH.

macOS

With Homebrew, from the codescarlett tap:

terminal
brew install scarlettiron/tap/vmynt

Builds for Apple Silicon and Intel are both published; Homebrew picks the right one.

Linux

Debian, Ubuntu and derivatives (apt)

Add the signed Vmynt package repository once, then install and update with apt like anything else:

terminal
# 1. trust the repository's signing key
curl -fsSL https://scarlettiron.github.io/vmynt/apt/vmynt-archive-keyring.gpg | sudo tee /usr/share/keyrings/vmynt-archive-keyring.gpg >/dev/null
# 2. add the repository
echo "deb [signed-by=/usr/share/keyrings/vmynt-archive-keyring.gpg] https://scarlettiron.github.io/vmynt/apt stable main" | sudo tee /etc/apt/sources.list.d/vmynt.list
# 3. install
sudo apt update && sudo apt install vmynt

Packages are published for amd64 and arm64.

Any distribution (Homebrew)

terminal
brew install scarlettiron/tap/vmynt

Verify a download

Each release has a SHA256SUMS file listing the SHA-256 checksum of every other file. Download it beside your file and compare:

PowerShell
Get-FileHash .\vmynt-*.zip -Algorithm SHA256
Select-String vmynt- .\SHA256SUMS
macOS / Linux
shasum -a 256 --ignore-missing -c SHA256SUMS

Package managers do this for you: winget, Chocolatey and Homebrew check the checksum, and apt checks the repository's signature.

Check it works

terminal
vmynt --version
vmynt doctor

vmynt doctor checks your hypervisor, permissions and tools, and prints a fix for anything that's missing. Then head to your first project.

Shell completion

Tab completion for commands and flags, for bash, zsh, fish and PowerShell:

terminal
# bash
vmynt completion bash > ~/.local/share/bash-completion/completions/vmynt
# zsh (a folder on your $fpath)
vmynt completion zsh > ~/.zfunc/_vmynt
# fish
vmynt completion fish > ~/.config/fish/completions/vmynt.fish
PowerShell
vmynt completion powershell | Out-String | Invoke-Expression
# to keep it, add that line to your $PROFILE

Host requirements

What each kind of host needs to run VMs. vmynt doctor checks all of it.

HostNeedsNotes
Windows 10/11 Pro, Enterprise or Education; Windows Server Hyper-V turned on, and you are an administrator or in the Hyper-V Administrators group: Add-LocalGroupMember -Group 'Hyper-V Administrators' -Member $env:USERNAME, then sign out and back in Windows Home has no Hyper-V. vmconnect.exe (the Hyper-V management tools) opens the console and the Enhanced Session desktop.
Linux /dev/kvm, libvirt with QEMU and OVMF, and your user in the libvirt group: sudo apt install qemu-system libvirt-daemon-system ovmf or sudo dnf install @virtualization, then sudo usermod -aG libvirt $USER and log in again Vmynt uses qemu:///system, libvirt's default network and the default storage pool (it starts or creates them). virt-viewer for the console (optional); FreeRDP or Remmina for the desktop.
macOS 13 or newer, Apple Silicon or Intel vfkit (Homebrew installs it with Vmynt, or brew install vfkit) The desktop opens in Microsoft's Windows App (App Store) over RDP. Apple Silicon runs arm64 guests.
All ssh and ssh-keygen on your PATH Used by status, ssh, exec and logs; Vmynt makes its own key with ssh-keygen and adds it to every VM. Built into Windows 10+, macOS and Linux.

Give a VM real resources: the built-in defaults are 4 vCPUs, 8 GB of RAM and a 40 GB system disk (the desktop blueprints ask for 12 GB of RAM), all set in the config. The first build downloads an install ISO of 1 to 3 GB, cached for later builds.

Updating

terminal
winget upgrade CodeScarlett.Vmynt      # winget
choco upgrade vmynt                    # Chocolatey
brew upgrade vmynt                     # Homebrew
sudo apt update && sudo apt upgrade    # apt

Uninstalling

terminal
winget uninstall CodeScarlett.Vmynt    # winget
choco uninstall vmynt                  # Chocolatey
brew uninstall vmynt                   # Homebrew
sudo apt remove vmynt                  # apt
# apt: also remove the repository and its key
sudo rm /etc/apt/sources.list.d/vmynt.list /usr/share/keyrings/vmynt-archive-keyring.gpg

Uninstalling the program leaves your VMs and ~/.vmynt alone. Remove VMs first with vmynt remove --delete-disks if you want them gone, then delete ~/.vmynt. Each project's .vmynt/ folder is yours to keep or delete.
